# Spec Delta

## ADDED Requirements

### Requirement: 介入点参数的三层条件显示
介入点参数族 SHALL 按「父开关 → 方法开关 → 递归层数」层级条件显示：候选点计算总开关关闭时，该类买卖点的其余三个介入点参数（区间套开关、递归层数、辅助确认开关）SHALL NOT 出现在配置界面中；总开关开启而区间套开关关闭时，递归层数 SHALL NOT 出现。条件判定依据 SHALL 是抽屉草稿的当前值——用户切换草稿开关时，相关参数项的显隐即时变化。

#### Scenario: 总开关关闭时子参数不显示
- **WHEN** 草稿中某类买卖点的候选点计算总开关为关闭
- **THEN** 该类的区间套开关、递归层数、辅助确认开关均不出现在界面中

#### Scenario: 总开关开启显示方法开关
- **WHEN** 用户在草稿中开启某类候选点计算总开关
- **THEN** 区间套开关与辅助确认开关立即出现；递归层数在区间套开关开启前不出现

#### Scenario: 区间套开关开启显示递归层数
- **WHEN** 草稿中区间套开关从关闭切换为开启
- **THEN** 递归层数立即出现

#### Scenario: 关闭区间套时层数隐藏且取值不丢失
- **WHEN** 用户曾将递归层数设为 2，随后关闭区间套开关再重新开启
- **THEN** 递归层数重新出现且仍为 2（隐藏不等于清除草稿取值）
