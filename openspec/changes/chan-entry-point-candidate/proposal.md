# Proposal

## Why

区间套目前只是「一买候选点上的备查特征」（`bsp1_qjt_hit`），且 2 买/3 买完全没有介入点概念。实战中真正需要的是缠论意义上的「介入点（候选点）」：本级别背驰段出现后，由次级别逐级验证力度衰竭（区间套），或由次级别确认的二买/三买辅助确认，任一命中即定位介入点。同时现有配置项「计算区间套特征」「区间套递归几层」无条件平铺显示，与「区间套只为介入点服务」的语义不符。

## What Changes

- **新增介入点候选判定层（路线 A）**：在买卖点判定收尾后置计算「介入点候选」标记，按类型分三种必要条件 + 双方法判定：
  - 1买（卖镜像）：必要条件 = 本级别下跌背驰段（T1 候选链成立中）；方法1 = 区间套递归（次级别逐层走出完整背驰结构 + 最低级别底分型/顶分型确认，层数受递归参数约束）；方法2 = 辅助确认信号（次级别出现已确认的二买/三买，卖侧二卖/三卖）
  - 2买：必要条件 = 一买确认后向上段成立、当前处于回落段且回落段内部结构未完成；方法1 = 次级别在回落段范围内走出「一买式」背驰 + 底分型；方法2 = 次级别在回落段范围内出现已确认二买/三买
  - 3买：必要条件 = 向上离开段成立、当前处于回抽段且回抽段内部结构未完成；方法1 = 次级别在回抽段范围内走出「一买式」背驰 + 底分型；方法2 = 次级别在回抽段范围内出现已确认二买/三买
  - 方法1与方法2任一满足即介入点成立；两方法均可独立开关
- **窗口口径修正**：方法1/方法2 的判定窗口主体为各自的**待确认段**（1买 = c 背驰段，2买 = 回落段，3买 = 回抽段，与既有 `_c_window_of` / ladder 佐证轴窗口同源），不是整条线段；方法2 右端**至数据末端**（容纳确认滞后；N 笔限制留作后续配置项，本期不实现）
- **不改成立性（BREAKING 无）**：介入点是既有 T1/T2/T3 点上的独立标记层，六类买卖点的成立性与输出数量完全不变；`bsp1_qjt_hit` 特征、ladder 阶梯语义保持
- **配置三层联动**：每类点新增参数族 `bsp{1,2,3}_entry`（是否开启候选点计算）→ `bsp{1,2,3}_qjt`（方法1，仅 entry 开启时显示）→ `bsp{1,2,3}_qjt_depth`（递归层数，仅 qjt 开启时显示）+ `bsp{1,2,3}_aux_confirm`（方法2，仅 entry 开启时显示）；全部进配置指纹，`legacy` 档显式全关
- **落库**：`bsp_index` 惰性 DDL 加介入点列（成立标记 + 命中方法 + 递归层级），随增量重算刷新（盘中实时性由 (b) 链路天然成立，不单独实现 (a)）；监控规则消费该列（低优先级，不阻塞主链路）
- **展示**：不新增 `bsp_type` 枚举（保住按笔去重 D22 口径）；类型化展示——K 线图 `chan_bsp` 标签合成（如 `1B·介`）、买卖点列表类型列同样合成、类型筛选下拉增加伪类型项（翻译为 entry 列条件）
- **回归保证**：`bsp_standard_equivalence.py` 等既有等价基线必须逐笔通过；介入点开关全关时输出与现状逐笔一致

## Capabilities

### New Capabilities
- `chan-entry-point`: 介入点候选判定——三类买卖点各自的必要条件与双方法判定（区间套递归 / 辅助确认信号）、买卖对称、窗口口径（待确认段 + 方法2右端至数据末端）、后置计算不改成立性

### Modified Capabilities
- `chan-config`: 参数可配置范围与指纹范围扩展——新增 12 个介入点参数键（3 类点 × 4 键），三层 visible_when 元数据，legacy 档显式全关
- `chan-config-page`: 抽屉交互——介入点参数族按「父开关 → 方法1开关 → 递归层数」层级条件显示，未开启时对应参数不出现
- `bsp-index`: 介入点落库与查询——`bsp_index` 加介入点列（惰性 DDL）、历史买卖点查询支持介入点伪类型筛选、序列化与 K 线页 / 买卖点列表的类型化展示合成

- **内核**：`ChanAnalyse/BuySellPoint/BSPointList.py`（介入点后置注解通道，模式同 `_annotate_qjt`）、`BSPointConfig.py`（新配置键与校验）、`ChanConfig.py`（键透传）
- **WebAPI**：`chan_config_schema.py`（12 键元数据 + conditional）、`chan_config_store.py`（校验/派生/档位回填）、`config_fingerprint.py`（指纹段）、`bsp_store.py`（惰性 DDL 加列 + 查询过滤）、`incremental_engine.py`（落库行拼接，位置同 `cal_ladder`）、`bsp_ladder.py` 的窗口映射函数复用
- **前端**：`ChanConfigDrawer.vue`（visible_when 已有机制直接复用）、`utils/bsp.ts`（标签合成）、`chan_bsp.ts`（meta 加 entry 字段）、BspView 类型筛选与列表列
- **DDL**：`bsp_index` 加列走惰性 DDL + `WebAPI/update-win.sql` 幂等追加（本变更在 Windows 机器开发）
- **文档**：`文档/缠论策略.md` 同步介入点判定逻辑（既有文档同步约定）
- **不动**：`CChan`/`CBiList`/`CSegListChan`/`CZSList`/`CBSPointList` 的既有判定链路、`chan-bsp1-qjt` 的特征语义、ladder 三轴/五轴/四轴语法
