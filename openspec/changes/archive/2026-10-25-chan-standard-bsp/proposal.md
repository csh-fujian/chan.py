# Proposal: chan-standard-bsp（买卖点对齐缠论标准定义）

## Why

本仓库 `ChanAnalyse/` 的买卖点实现，经《文档/一买一卖差异点说明.md》《文档/二买二卖差异点说明.md》《文档/三买三卖差异点说明.md》三份逐条对照缠师原文的核查，六类买卖点（T1 / T1P / T2 / T2S / T3A / T3B）呈现出**两极分化**：

- **T1（第一类买卖点）偏离最严重**：实现的是「线段内最后一个中枢的离开笔背驰」，而非严格意义的「趋势背驰一买」。五处缺口——无趋势前提（单中枢盘整即判 T1）、默认 `divergence_rate=inf` 使背驰恒成立、不要求创趋势新低、缺 DIF（黄白线）判据与零轴回抽前提、离开/回抽为单笔而非次级别走势类型。41 只 A 股日线（2019 起、QFQ）实测：默认配置产出 258 个 T1，其中 96% 处于单中枢结构；逐级加严格门控后收敛到 5~23 个，数量级差异 10~50 倍。
- **T3A（三买后）实现正确**：9/9 样本满足「中枢 → 突破笔向上/向下突破 → 下一笔回抽不回到中枢区间」的完整序列，可直接使用。
- **T2（二买）骨架正确但口径不统一**：`+1/+2` 的时序骨架对，「不破一买极值」由 `max_bs2_rate <= 1` 的 assert 在数学上自动保证；但 `relate_bsp1` 用候选口径而跟随校验用成立口径，首线段分支的配置方向取反（`seg.is_up()`），回调是单笔而非次级别走势。
- **T2S（类二）名不副实**：理论定义是「中枢内的多次回抽」，代码中**完全不引用任何中枢对象**，实际是「二买后每隔一笔、与前笔重叠、未破参照点的同向笔」的机械筛选；`bsp2s_follow_2` 语义与文档相反且默认阈值下实测完全无效（157 → 157）。
- **T3B（类三）不是三买**：只保留了「回抽不进中枢区间」这一条价格判据，**不要求是突破后的第一次回抽**（实测间隔 2/4/10/14 笔，0 个为 1），也不校验突破笔方向；11 个样本中 7 个与 T2/T2S 落在同一笔，3 个在突破笔之后已有回中枢笔（中枢支撑已被证伪）。

这些偏离直接污染下游 `bsp_index` 落库、买卖点绩效、监控预警与策略任务。本变更以「与缠论理论一致」为唯一验收标准，改造六类买卖点的判定，并把「次级别走势类型」落到天然具备内部结构的**线段级别**（`seg_bs_point_lst`）。

## What Changes

### 一买一卖（T1 / T1P）

- **默认配置对齐理论与既有文档**：`divergence_rate` 由 `inf` 改为 `0.9`；`min_zs_cnt` 由 `1` 改为 `2`；新增 `bsp_preset` 配置项，`legacy` 值一键回退旧行为
- **新增一买严格判据（可独立开关）**：趋势前提（两中枢依次下移/上移）、创趋势新低（离开段须创趋势区间内全部同向要素的新低）、DIF 背驰（b/c 两段的 DIF 极值不创新低/新高）、零轴回抽（b/c 段之间 DIF 须过零）
- **力度算法补全**：`CBi` 新增 `diff_peak`（真 DIF 线极值，修正现有 `diff` 名不副实）；`CSeg` 补齐 MACD 系列算法（现仅 `slope`/`amp`），解除线段级别的 `slope` 硬编码
- **次级别落在线段级别**：把一买判据抽为与层级无关的纯函数，线段级别（本级别=线段的线段、次级别=线段）产出「标准一买」
- **放宽 4.8**：取消「中枢须延伸到线段末笔」的强制转 T1P 条件（实测该条把 114 个合格候选挤入 T1P）
- **候选/成立分层**：新增 `bsp1_sure_list` / `bsp1_sure_dict` 只收已成立点；`bsp2_follow_1` / `bsp3_follow_1` 的校验与 `relate_bsp1` 的取值统一改用成立口径

### 二买二卖（T2）

- **统一 `relate_bsp1` 口径**：`treat_bsp2` 中 `real_bsp1 = self.bsp1_dict.get(...)`（候选口径）改为只查成立集合，杜绝「二买引用未成立一买」
- **修正首线段分支的配置方向**：`treat_bsp2` 的 `GetBSConfig(seg.is_up())` 改为 `seg.is_down()`，与同函数内的 `treat_bsp2s` 及其他分支一致
- **新增回调结构开关 `bsp2_retrace_zs`（默认关闭）**：开启后要求回调笔与一买所在线段的多笔中枢存在区间关联，把「回调」从中枢无关的单笔提升为「中枢区间内的次级别回抽」

### 类二（T2S）

- **修正 `bsp2s_follow_2` 语义**：从「二买未成立分支里的 return」改为「类二必须跟在已成立的二买之后」，与文档描述对齐。实测修正后在 `max_bs2_rate=0.618` 时 T2S 由 83 降到 60，开关真正生效
- **补中枢前提 `bsp2s_require_zs`（默认开启）**：要求 T2S 所在笔的末端值落在 `seg.zs_lst` 中某个多笔中枢的 `[low, high]` 区间内。实测 157 个 T2S 中 151 个与中枢有交集、90 个末端值在中枢内、6 个所在线段无多笔中枢
- **统一回撤率量纲 `bsp2s_rate_mode`**：默认改为与二买一致的 `amp` 口径（`bsp2s_bi.amp()/break_bi.amp()`）。实测当前 16 个两口径差 ≤0.05、58 个差 >0.05、83 个差 >0.2；改用 amp 后 `max_bs2_rate=1.0` 时 157 → 144

### 三买三卖（T3A / T3B）

- **T3A 保持判定不变**，仅统一 `bsp3_peak` 的判据对象：从「回抽笔是否冲破中枢极值」改为「突破笔（离开笔）是否冲破中枢极值」，与 `Document/README.md` 的描述对齐
- **T3B 重新定义为标准三买**：以「线段内最后一个多笔中枢的离开笔」为锚，要求离开笔方向正确并真正突破中枢（买：向上且 `_high() > zs.high`），取离开笔之后**第一笔**反向回抽，要求不回中枢区间；不再从一买笔 +2 起逐笔扫描、遇回中枢即 `break` 而非 `continue`
- **`bsp3_follow_1` 改用一买成立集合**：不再查 `bsp_store_flat_dict`（含全部类型），避免二买点误充一买
- **`strict_bsp3` 两条分支语义统一**：统一为「中枢紧邻一买」
- **新增 `bsp3b_mode` 档位**：`standard`（默认，上述重定义）/ `legacy`（现有宽松扫描）

### 跨类型

- **同笔多类型去重标记**：`CBS_Point` 增加 `type_priority` 与下游可读的 `primary_type`，供 `bsp_index` 按笔去重时不重复计入（不改变 `type` 列表本身）
- **BREAKING**：默认输出语义变更，T1 数量预计下降一个数量级以上，PG `bsp_index` 存量行需全量回刷
- **BREAKING**：`CChan`/`CBi`/`CSeg`/`CZS`/`CBSPointList` 的计算逻辑将被修改，破例于仓库既有「不改核心计算」约定（本 proposal 即该破例的书面记录）

## Capabilities

### New Capabilities

- `chan-bsp-standard`: 六类买卖点的标准判定规范——一买的趋势前提、创趋势新低、面积/DIF 双背驰判据、零轴回抽；二买的一买跟随与回调结构；类二的中枢前提与量纲统一；三买的中枢锚定、突破方向与第一次回抽；以及各档位预设与回退语义

### Modified Capabilities

- `bsp-index`: 买卖点索引的产出口径随六类判定变更而变——各 `bsp_type` 的索引行数量与分布改变，存量需全量回刷；同笔多类型需按 `primary_type` 去重；绩效统计的分母随之变化

## Impact

- **核心库（破例修改）**：`ChanAnalyse/ChanConfig.py`（默认值与预设）、`ChanAnalyse/BuySellPoint/BSPointConfig.py`（新配置项）、`ChanAnalyse/BuySellPoint/BSPointList.py`（六类判据、候选分层、跟随口径、中枢校验）、`ChanAnalyse/BuySellPoint/BS_Point.py`（类型优先级）、`ChanAnalyse/ZS/ZS.py`（背驰判据）、`ChanAnalyse/Bi/Bi.py`（`diff_peak`）、`ChanAnalyse/Seg/Seg.py`（MACD 算法补全）、`ChanAnalyse/Common/CEnum.py`（新增算法枚举）
- **下游数据**：PG `bsp_index` 表（`WebAPI/bsp_store.py`、`WebAPI/incremental_engine.py`）存量行需按新口径全量重算；`WebAPI/bsp_ladder.py` 的 L3 背驰预警口径需与新判据对齐
- **调用方显式覆盖**：`main.py`、`App/ashare_bsp_scanner_gui.py` 中显式写死的 `divergence_rate=inf` / `min_zs_cnt=0` 需改为预设或移除，否则覆盖新默认值
- **前端**：买卖点类型与数量变化会直接体现在 K 线覆盖层与买卖点页；前端不暴露这些内核参数，无需改前端代码，但需同步文案与空态
- **文档**：`文档/缠论策略.md` 的 3.6/3.7/11 章、`Document/README.md` 的买卖点参数段、以及三份《xx买xx卖差异点说明》的结论回标
- **不改动**：笔、线段、中枢的构造算法本身（仅补力度算法与读取方式），DuckDB 持久化层，前端构建
