## MODIFIED Requirements

### Requirement: 买卖点标记确认阶梯悬浮提示

K 线主图买卖点覆盖层（`chan_bsp`）SHALL 支持鼠标悬浮交互：悬浮任一买卖点标记时展示 tooltip，内容按该买卖点的阶梯取值区分：`L4`（确认买卖点）展示确认说明与仓位指引；三轴组合值（如 `L1|L2-3|L3-3`）SHALL 按轴解析并列展示各轴已达成标签——进度轴（判据链推进：L1 前半链 / L2 后半链）、佐证轴（次级结构佐证：L2-3 已确认子级点 / L2-2 子级候选部分达成 / L2-1 子级分型）、分型轴（反转强弱：L3-3 强 / L3-2 中 / L3-1 弱），各轴附带名称与说明，已达成的标签 SHALL 高亮标识；`ladder` 为 NULL 的标记展示「未定级」。数据侧依赖 `/api/klines` 响应的 `bsp[].ladder` 字段（组合字符串或 NULL）。

#### Scenario: 悬浮展示级别与说明

- **WHEN** 用户鼠标悬浮 K 线主图上的任一买卖点标记
- **THEN** 出现 tooltip，按该标记的阶梯取值展示对应轴的名称与说明，已达成的标签高亮

#### Scenario: 无级别数据时的兜底

- **WHEN** 响应中某非一买买卖点的 `lader` 为 NULL 或字段缺失（如降级或旧缓存）
- **THEN** tooltip 以未定级兜底展示，不报错、不阻断图表渲染

#### Scenario: 悬浮展示三轴组合

- **WHEN** 用户鼠标悬浮 K 线主图上阶梯为 `L2|L2-3|L3-2` 的买卖点标记
- **THEN** tooltip 展示三个轴区块——进度轴 L2（后半链达成）、佐证轴 L2-3（已确认子级点）、分型轴 L3-2（中等收复），各达成标签高亮并附带说明

#### Scenario: 悬浮展示确认级别

- **WHEN** 用户鼠标悬浮阶梯为 `L4` 的买卖点标记
- **THEN** tooltip 展示确认买卖点说明与仓位指引（满仓/空仓按方向）

#### Scenario: 未定级兜底

- **WHEN** 响应中某非一买买卖点的 `ladder` 为 NULL 或字段缺失
- **THEN** tooltip 以「未定级」兜底展示，不报错、不阻断图表渲染

#### Scenario: 级别随数据刷新更新

- **WHEN** 数据重算后某买卖点的 `ladder` 发生变化（如 `L1|L3-1` → `L2|L2-3|L3-2`，或推进到 `L4`）
- **THEN** 刷新后悬浮同一标记的 tooltip 展示新阶梯
