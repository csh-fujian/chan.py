## 一、理论定义

### 1.1 2 买 / 2 卖

第二类买点：第一类买点出现后，**次级别回调**不跌破该第一类买点，随后的上涨的起点。
第二类卖点对称：第一类卖点后，次级别反弹不升破第一类卖点高点。

判定要素：

| 编号 | 要素 | 严格内容 |
|---|---|---|
| A | 前提 | 必须先有**成立**的第一类买卖点 |
| B | 时序 | 一买后**第一次**次级别回调（向下） |
| C | 结构 | 回调是「次级别走势类型」，不是单笔 |
| D | 价格 | 回调低点**不跌破**一买低点（卖点对称） |
| E | 后续 | 回调结束后趋势未延续（未创新低），上涨的起点即二买 |

### 1.2 类二买 / 类二卖（本仓库自定义扩展）

理论中的「类二买」通常指：中枢形成过程中，**在中枢内**反复回抽形成的、与二买同侧的次级别买卖点，级别低于二买但数量更多。

### 2.3 与「次级别走势类型」的关系（笔级别单笔口径）

笔级别 `bs_point_lst` 的本级别 = 线段、次级别 = 笔，回抽恒为单笔——这是**文档明示的
地址化简化口径**，不直接当作「次级别走势类型」。严格语义由两条路径承担：

- **线段级别**（`seg_bs_point_lst`）：线段的线段天然具备内部结构，「次级别走势类型」由这一层承担。实测 41 只日线线段级 T2 仅 1 个且与笔级零重合，笔级别数据上无实质暴露。
- **五轴阶梯的佐证轴**（chan-standard-bsp2-change）：回调笔窗口映射子级别结构证据（S3 子级已确认同向点 / S2 子级候选 / S1 子级末端同向分型），在 WebAPI 层以证据标注方式补充「次级别确认」信息。

## 三、确认阶梯（T2/T2S 五轴）

未确认的 T2/T2S 候选点携带五轴独立证据（chan-standard-bsp2-change），落库于
`bsp_index.ladder`（轴顺序固定：进度 → 佐证 → 确认 → 分型 → 时间），已确认为 `L4`
单值，第三类家族见《三买三卖差异点说明.md》（`chan-standard-bsp3-change` 起为
`S|C|K|T` 四轴、无进度轴）。语法独立于 T1 的 L 编号，靠 bsp_type 路由。

| 轴 | 取值 | 语义 |
|---|---|---|
| **进度轴** | `P1` / `P2` | 判据链短路位置：已过 ≤3 项 → `P1`，>3 项或全过未确认 → `P2` |
| **佐证轴** | `S3` / `S2` / `S1` | 回调笔窗口映射的子级别结构证据（见 §2.3） |
| **确认轴** | `C3` / `C2` / `C1` / `C0` | 事后价格确认（窗口 = `bsp2_confirm_window` 笔，默认 2）：`C3` 突破 `break_bi` 端点 / `C2` 收复振幅一半 / `C1` 窗口走完未动（终态降级，不撤销行）/ `C0` 窗口不足（进行中） |
| **分型轴** | `K3` / `K2` / `K1` | 回调笔末端分型强弱（实体口径，与 T1 分型轴同源分级） |
| **时间轴** | `T3` / `T2` / `T1` | 回调速度比 `v = (amp(bsp2_bi)/amp(break_bi)) / (klu_cnt(bsp2_bi)/klu_cnt(break_bi))` 三档：`v ≤ 0.5` → `T3`；`0.5 < v ≤ 1.0` → `T2`；`v > 1.0` → `T1` |

确认轴是要素 E（「后续上涨」）的显式判据，与结构确认（`is_sure` 水位线口径）正交：
后者回答「该点会不会因重算消失」，前者回答「该点事后是否走对」。实证分布
（41 只日线，T2：C3 75% / C2 25% / C1 0%）见《文档/二买确认轴实证报告.md》。

五轴全部是证据标注，**不改变成立判据**；量能与 ML 打分显式排除在候选判断之外。
配置组：`bsp2_confirm_window`（默认 2）/ `bsp2_confirm_level`（strong/weak）/
`bsp2_time_axis_strong` / `bsp2_time_axis_weak`（0.5 / 1.0）。

## 四、最终结论

| 维度 | 结论 |
|---|---|
| 一买 → 二买的时序 | ✅ 正确（固定 `+1/+2` 笔，锚点取线段末笔） |
| 「回调不破一买」价格约束 | ✅ 数学上自动成立（`max_bs2_rate ≤ 1` + 振幅比判据） |
| 二买必须有成立的一买 | ✅ `relate_bsp1` 与 `follow` 校验统一为 `bsp1_sure_dict` 成立口径 |
| 首线段配置方向 | ✅ 统一为 `seg.is_down()` |
| 类二回撤率量纲 | ✅ `amp` 口径，与二买同构（`disp` 保留为旧档位） |
| 类二中枢前提 | ✅ `bsp2s_require_zs` 默认开启（末端价格落在多笔中枢区间内） |
| 类二跟随二买 | ✅ `bsp2s_follow_2` 判断在函数入口，语义与文档一致 |
| 回调为次级别走势 | ⚠️ 笔级别为文档明示的单笔简化口径；严格语义由线段级别与佐证轴承担（§2.3） |
| 事后价格确认（要素 E） | ✅ 五轴确认轴承担（§三），与结构确认正交 |

**一句话**：二买/类二的判据链骨架正确、口径统一，可直接使用；「次级别走势类型」
在笔级别是明示的单笔简化（佐证轴与线段级别补足语义），「事后确认」由确认轴
显式承担（不再依赖结构确认的隐含语义）。

### 回退方式

如需逐笔复现改造前的输出：`CChanConfig({"bsp_preset": "legacy"})`。
单项回退用对应枚举开关，例如 `bsp2s_require_zs=False`、`bsp2s_rate_mode="disp"`。
