chan.py 缠论量化

暗色专业终端风格，对标同花顺 / 富途 / TradingView。金融语义遵循 A 股「红涨绿跌」—— 涨 / 阳线 / 买点 / 盈利为正 = 红，跌 / 阴线 / 卖点 / 盈利为负 = 绿。

暗色主题 红涨 绿跌 1440 × 900 共 10 页
01 独立单页
K 线图表页

交互式浏览单只股票 K 线与缠论结构——笔 / 线段 / 笔中枢 / 线段中枢 / 买卖点，叠加成交量与 MACD 副图。
02 /watchlist
我的自选

文件夹分类管理自选股票，查看名称 / 编码 / 股价 / 行业，支持搜索、批量移出与加入自选弹窗。
03 /bsp
历史买卖点

按周期 / 日期 / 类型查询全市场买卖点股票，板块聚合，批量加入自选 / 监控，支持区间套下钻。
04 /monitor
股票监控

监控列表 + 每只盈利走势折线 + 总体盈利汇总，支持手动结束监控与状态流转。

其余页面

05/monitor/completed
监控完成

展示已结算卖出的监控股票，对盈利 < 5% 的标的做大模型亏损归因（缠论失效 / 计算逻辑错误）。
06/performance
买卖点绩效

按买卖点类型与周期统计历史胜率、盈亏比、样本数，柱状图对比胜率，下钻样本明细。
07/screener
条件选股

把周期 / 日期 / 买卖点类型 / 行业 / 指标阈值组合成可复用选股策略并执行扫描。
08/alerts
预警提醒

管理预警规则（价格 / 买卖点 / 监控卖点）与查看站内通知，未读高亮 + 一键标记已读。
09/login · 不套壳
登录

用户认证入口，独立居中页面（不套 AppShell），终端提示行点缀 + 登录失败提示。
10/system
权限管理

admin 专属，管理用户、角色与角色-权限配置（权限树勾选 menu:* + manage）。
